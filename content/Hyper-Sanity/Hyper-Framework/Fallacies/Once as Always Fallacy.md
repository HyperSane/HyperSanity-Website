**Summary:**  
The “Once as Always” fallacy is a flawed **cognitive shortcut** where someone **assumes** that a **single** use or method implies **permanent** or **consistent** usage—across time, contexts, or identities. 

---

## 🔍 Fallacy Name: **Once as Always**

### 📘 Definition:

> The fallacy of assuming that because a person (or system) used a method or tool once, they always use it—or that one-time use defines ongoing identity, behavior, or intent.

---

## ⚒️ Real-World Examples

### 1. **Carpentry Analogy**

- **False Claim**: “You used a hammer once, so you must use a hammer for everything.”
    
- **Reality**: Carpenters use different tools (chisels, saws, drills) for different jobs. Using a tool once doesn't define the craft.
    

### 2. **AI Usage Analogy**

- **False Claim**: “You used AI for this task, so you must be using AI for everything.”
    
- **Reality**: People use AI tools selectively, contextually, and sometimes only once. This doesn't imply dependence or total outsourcing of thought.
    

---

## 🧠 Ontological Structure

|Layer|Description|
|---|---|
|**Phenomenon**|A person uses a tool (e.g., AI, hammer) in a specific context.|
|**Cognitive Shortcut**|Observer falsely universalizes that behavior.|
|**Fallacy**|Assumes single usage = consistent or defining trait.|
|**Impact**|Erases nuance, enforces identity essentialism, encourages ignoration.|

---

## ⚠️ Error Type: **Temporal Overgeneralization**

- Related to: **Essentialist Fallacy**, **Hasty Generalization**, **Continuum Fallacy**
    
- Distinct because it fixates on a **time-snapshot** and extrapolates **perpetuity** from it.
    

---

## 🧩 Use in Argumentation

- Used to **discredit** or **dismiss**: "You used AI once, so you're not authentic."
    
- Used in **identity attacks**: “You once contradicted yourself, so your entire logic is invalid.”
    
- Enforces **ontological essentialism**: reducing dynamic beings to static labels.
    

---

## ✅ Counter Logic

- **Functional tools ≠ personal traits**
    
- **One-time use ≠ permanent behavior**
    
- **Contextual actions ≠ essential identities**
